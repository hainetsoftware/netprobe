# Repository instructions

- Never include generated report JSON files (for example, `netprobe_report_*.json`) in commits or pushes. Keep them local, and do not stage them. The repository `.gitignore` excludes these reports; if one is already tracked, untrack it without deleting the user's local copy.
- Write commit messages, pull request titles and descriptions, and GitHub comments in English. Follow the style of existing repository commits and comments. Apply this convention to all collaborating agents and include it in delegated task instructions.
